# Causal-Hot-Jupiter-Inflation

Code base for the paper **"Causes of Hot Jupiter Inflation from Causal Discovery"**.

## Project status

This repository is being organized ahead of the full code and data upload.

## Scope

The project explores possible causes of hot Jupiter inflation using causal discovery methods.

## Planned repository structure

The sections below describe the intended organization once upload is complete:

- `data/` — curated datasets and data dictionaries
- `src/` — data processing, causal discovery, and analysis code
- `notebooks/` — exploratory and reproducibility notebooks
- `results/` — generated figures, tables, and model outputs
- `docs/` — supporting notes and methodology details
